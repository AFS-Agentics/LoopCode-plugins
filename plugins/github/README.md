# GitHub

GitHub is a LoopCode MCP plugin for working with repositories, issues, pull requests, code search, and related GitHub resources through GitHub's hosted MCP endpoint.

## Setup

Set the `GITHUB_PERSONAL_ACCESS_TOKEN` environment variable to a GitHub personal access token with access to the repositories you want LoopCode to use. Then install and enable the GitHub plugin in LoopCode.

This first version contributes only the GitHub MCP server configuration.
